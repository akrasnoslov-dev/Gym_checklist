# Documentation map

Read `AGENTS.md` first. It is the only execution and scheduling rulebook.
Do not preload this directory: open the smallest relevant document.

| Need | Source |
| --- | --- |
| Live checkpoint and exact next action | `progress.md` |
| Task definitions and acceptance criteria | `implementation_plan.md` |
| MVP behavior | `product_spec.md` |
| UX behavior and accessibility | `ux_spec.md` |
| Final UI/UX design process and source priority | `ui_redesign_plan.md` |
| Phase 4 UI/UX decisions for the final candidate | `ui_research_phase4.md` |
| Durable Phase 5 and implementation design constraints | `ui_ux_design_rules.md` |
| Architecture, data and CI boundaries | `architecture.md` |
| Firebase, sign-in, security, offline and deletion setup | matching topical document |
| Physical-iPhone acceptance | `mvp_acceptance_checklist.md` and `mvp_external_acceptance_handoff.md` |
| Deferred paid release work | `release/` |
| Approved current brand assets | `brand/README.md` |

`codex_instructions.md` is a command reference. `codex_master_prompt.md` is a
copy-paste launch prompt. Neither overrides `AGENTS.md`, current explicit user
decisions, or `progress.md`.
