# Gym Checklist — Brand Assets

Status: **current approved logo direction** as of 2026-08-28. Keep using it until the user explicitly replaces it.

## Approved direction
- Mark: combined kettlebell / G-shape / checklist tick / barbell.
- Palette: lime/green into mint green on an off-white background.
- Purple is not part of the current approved brand direction.
- Wordmark in the approved reference reads **Gym Checklist**, with “Gym” in the green treatment and “Checklist” in dark charcoal.

## Files
- `gymchecklist-logo-mark.svg` — scalable logo mark for documentation/design handoff.
- `gymchecklist-app-icon-1024.png` — 1024×1024 app-icon master used by the iOS project.
- App runtime copy: `GymChecklist/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`.

The app-icon master intentionally has no baked rounded-corner mask or drop shadow; iOS applies the icon mask itself.

This approval covers the current product logo/app icon. App Store listing metadata, screenshots, distribution signing, and other paid-release work remain separate.
